Local Data

ZGB Native stores app settings, queue content, saved plans, recent broadcast records, and related local configuration on the user's Mac. The production authorization flow does not persist OAuth access or refresh tokens inside the macOS app. If optional local OAuth backend mode is used on macOS for development or diagnostics, Zoom authorization tokens are stored by the local backend in the user's macOS Keychain so the app can join meetings and request Zoom credentials.
