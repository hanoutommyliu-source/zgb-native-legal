Required Beta Evidence

Secure Software Development Life Cycle

ZGB Native uses a lightweight SSDLC covering security requirements, design review, secret-handling rules, implementation controls, verification gates, release/package review, and post-release vulnerability handling. Current controls include local-only backend binding, Zoom credential minimization, public HTTPS redirect/documentation pages, source-control exclusions for secrets and tokens, and scan/build verification before Marketplace review.

  • OAuth client secrets, OAuth tokens, meeting passcodes, and Zoom SDK credentials are excluded from source control, review packages, screenshots, support messages, and Marketplace comments.
  • The local OAuth helper binds to 127.0.0.1 only.
  • Public pages used for Marketplace documentation, privacy, terms, and OAuth redirect forwarding are served over HTTPS.
  • Verification gates include Xcode build/tests where applicable, backend syntax checks, SAST, dependency audit, DAST smoke checks, TLS checks, and package hygiene review.

Additional Policy Evidence

Security Policy

ZGB Native's security policy covers supported version, data protection, access control, transport security, secrets management, and local logging/diagnostics posture. The app stores queue content, saved session plans, recent broadcast records, and app configuration locally on the user's Mac. Broadcast messages are sent to Zoom meeting participants only when the user chooses to send them through the app.

Incident Management and Response Policy

Security incidents are triaged, contained, investigated, remediated, verified, documented, and escalated where required. Covered incidents include exposed OAuth client secrets, Meeting SDK secrets, OAuth tokens, refresh tokens, meeting passcodes, review packages containing unintended secrets, and vulnerabilities that could expose local data or misuse Zoom permissions.

Vulnerability Management Procedure

Vulnerabilities may be identified through SAST, dependency audit, DAST, manual code review, user reports, Zoom Marketplace review, or developer testing. Findings are triaged by affected component, exploitability, impact on secrets/tokens/local data/Zoom authorization, and applicable mitigations. Fixes are verified with targeted build, scan, DAST, TLS, package, or manual checks.

Infrastructure and Dependency Management Policy

ZGB Native consists of a native macOS SwiftUI app, a local Node.js OAuth helper backend bound to 127.0.0.1, Zoom OAuth/API/Meeting SDK integrations, public HTTPS GitHub Pages documentation/legal/OAuth redirect pages, and a GitHub Release review package. The current backend has no third-party production npm dependencies. Node dependency audit artifact: npm-audit-2026-05-29.json.

TLS 1.2 or Higher

Public ZGB Native pages are hosted on GitHub Pages over HTTPS. An OpenSSL TLS 1.2 handshake to hanoutommyliu-source.github.io:443 succeeded on 2026-05-29. The local backend uses http://127.0.0.1 only for loopback communication on the user's Mac; external Zoom, documentation, privacy, terms, redirect, and package-download traffic use HTTPS.
