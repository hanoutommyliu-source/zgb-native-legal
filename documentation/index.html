ZGB Native Documentation

Last updated: June 19, 2026

ZGB Native, also known as Zoom Game Broadcaster, is a macOS app for preparing timed Zoom breakout-room broadcast messages and sending them from a queue during a Zoom meeting.

Prerequisites

  • macOS 14.0 or later.
  • A Zoom account authorized for the ZGB Native Marketplace app.
  • A Zoom meeting where the signed-in Zoom user has permission to join and broadcast to breakout rooms.
  • Host, co-host, administrator, or equivalent Zoom permissions for the meeting actions being used.
  • Network access to Zoom services.

Adding the App

Install ZGB Native on macOS

  1. Download the ZGB Native review package: ZGB-0.1.0-review.zip.
  2. Unzip the package.
  3. Move ZGB.app to /Applications.
  4. Open ZGB.app.
  5. If macOS asks for confirmation because the app was downloaded from the internet, approve opening the app.

Authorize the Zoom App

  1. Open ZGB Native.
  2. Click Authorize with Zoom.
  3. Complete the Zoom authorization flow in the browser.
  4. Return to ZGB Native after the browser reports that sign-in is complete.

Troubleshooting link: see the Troubleshooting section on this page for authorization, account, meeting join, and breakout broadcast issues.

Usage

Join a Zoom Meeting

Use case: connect ZGB Native to the active Zoom session where the host will run broadcast prompts.

Prerequisites: the user must have an authorized Zoom account, a valid meeting number, the meeting passcode if required, and permission to join the meeting.

  1. Open ZGB Native.
  2. Enter the Zoom meeting number.
  3. Enter the meeting passcode if required.
  4. Click Join Meeting.
  5. Wait for the app to show that it has joined or is ready for Zoom breakout-room delivery.

Prepare Broadcast Messages

Use case: build a set of prompts, game instructions, or classroom cues before sending them during a live meeting.

Prerequisites: no active Zoom meeting is required to prepare messages. A Zoom meeting is required only when sending messages to breakout rooms.

  • Type a single message in the broadcast composer and choose a delay.
  • Paste a timed list into the import area. ZGB Native parses timings such as 30 sec, 2 min, or bracketed timing at the end of lines.
  • Review, reorder, delete, or expand individual queue entries before running the queue.

Run the Timed Queue

Use case: send a sequence of timed prompts to Zoom breakout rooms without manually tracking every cue.

Prerequisites: ZGB Native must be joined to the Zoom meeting, breakout rooms must be available, and the signed-in user must have the Zoom permissions required to broadcast to breakout rooms.

  1. Add or import queue messages.
  2. Review each message and delay.
  3. Click Run queue to send queued messages on their configured delays.
  4. Use Stop queue to cancel the active run.

Send a Specific Queue Item

Use case: restart from a selected prompt or manually send one item during a live session.

Prerequisites: the app must be joined to the Zoom meeting and the user must have permission to send breakout-room broadcasts.

  1. Expand the queue item.
  2. Click Send now on that item.
  3. Confirm the app labels the message as delivered to Zoom breakouts or reports a visible error.

Save and Load Session Plans

Use case: reuse a prepared set of game, class, workshop, or facilitation prompts across sessions.

Prerequisites: saved plans are stored locally on the user's Mac. iCloud availability depends on the user's macOS and iCloud configuration.

  • Save a queue as a session plan when you want to reuse it later.
  • Load a saved plan from the session plan list.
  • Use the Load Queue flow to select reusable queue files when available.

View Recent Broadcasts

Use case: inspect recent messages sent from the app for session continuity or troubleshooting.

Prerequisites: recent broadcast records exist only after messages have been sent from ZGB Native on that Mac.

  • Open the recent broadcasts area.
  • Review previous message text, timing, and delivery status shown by the app.

Troubleshooting

  • If authorization uses the wrong Zoom account, click Change Zoom Account, finish the browser sign-out, then click Authorize with Zoom again.
  • If Zoom says the application is not found, make sure the Zoom account is allowed to authorize the unpublished or review app.
  • If joining fails, verify the meeting number, passcode, account authorization, and host permissions.
  • If breakout broadcast fails, verify that breakout rooms are enabled and that the signed-in user has host, co-host, administrator, or other permissions required by Zoom.
  • Confirm that the hosted Cloudflare Worker backend is reachable from the configured Backend URL. If optional local backend mode is used for development or diagnostics, confirm that the backend is running and reachable at the configured local URL.
  • Do not put meeting passcodes, OAuth tokens, client secrets, or private credentials in support tickets or Marketplace comments.

Removing the App

Remove or Deauthorize from Zoom

  1. Sign in to the Zoom App Marketplace.
  2. Click Manage.
  3. Open Added Apps.
  4. Find ZGB Native.
  5. Click Remove.
  6. Select a removal reason if Zoom asks for one.
  7. Confirm removal.

Remove the Local macOS App

  1. Quit ZGB Native.
  2. Delete /Applications/ZGB.app.
  3. Use Change Zoom Account before deleting the app if you want to clear the hosted backend token for this app install's backend session. If optional local backend mode was used, also delete the ZGB Native OAuth token item from macOS Keychain.

Implications of Deauthorization

  • ZGB Native will no longer be authorized to use the removed Zoom account.
  • The app must be authorized again before it can join meetings through Zoom or send breakout-room broadcasts.
  • Previously saved local queues, saved plans, and recent broadcast records may remain on the user's Mac until the user deletes the local app data.

Data Handling After Removal

ZGB Native stores queue content, saved session plans, recent broadcast records, and Zoom configuration locally on the user's Mac. The production authorization flow does not persist OAuth access or refresh tokens inside the macOS app. The hosted Cloudflare Worker backend stores Zoom OAuth tokens in Workers KV for the app install's random backend session so it can issue short-lived join credentials. In optional local OAuth backend mode on macOS, Zoom OAuth tokens are stored by the local backend in the user's macOS Keychain. Deauthorizing the app in Zoom prevents future Zoom access for that account. Deleting the local app and clearing backend token storage removes the local app installation and authorization token data.

Support

For support, use the developer contact email listed on the Zoom Marketplace app profile. Include the app version, macOS version, the visible error message, and whether the problem happened during authorization, meeting join, queue preparation, or breakout-room broadcast.
